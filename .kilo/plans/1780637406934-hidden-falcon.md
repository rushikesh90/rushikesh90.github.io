# Fix for Overlapping Sidebar and TOC in Blog Posts

## Problem
In blog posts with `toc: true`, the author sidebar and table of contents (outline) overlap each other, particularly in the viewport width range of 925px to 1024px.

## Root Cause
1. Both sidebar.html and toc includes are rendered as siblings before the article content in `_layouts/single.html`
2. At `$large` breakpoint (925px+):
   - `.sidebar` (author profile): `span(2 of 12)` = ~16.67% width, `float: left`
   - `.sidebar__left` (TOC): `width: 21%` + `margin-right: 2%` = ~23% width, `float: left`
   - Combined width: ~39.67% taken by left sidebars
3. The `.page--with-left-toc` class (applied when `page.toc: true`) incorrectly sets content width to 77% instead of accounting for both sidebars
4. Expected content width should be: 100% - 39.67% = ~60.33%

## Solution
Fix the width calculation in `.page--with-left-toc` to properly account for both the author sidebar and TOC when they are both present (which is always the case for blog posts with toc: true).

## Changes Needed
1. Modify `_sass/layout/_page.scss`:
   - Update `.page--with-left-toc` width property from `77%` to approximately `60.33%`
   - For better maintainability, use Susy span function: `span(7 of 12)` which yields 58.33% (closest integer column approximation)
