# Plan to Fix Navigation Menu Issue

## Problem Analysis
1. Navigation menu only appears on the About page (index.md) because it's only in the custom default.html layout
2. Collection pages (projects, experience, education, news) use the theme's single.html layout which doesn't include our custom navigation
3. Need to remove News and Resources tabs from navigation as requested
4. Need to ensure navigation appears on all pages

## Solution Steps

### 1. Update Navigation Configuration
- Remove News and Resources entries from `_data/navigation.yml`

### 2. Create Base Layout with Navigation
- Create `_layouts/base.html` containing:
  - HTML structure with site header and navigation
  - Navigation loop using `site.data.navigation.main`
  - CSS styling for navigation (copy from current default.html)
  - Content block for child layouts to fill

### 3. Update Default Layout
- Modify `_layouts/default.html` to:
  - Use base.html as layout (front matter: `layout: base`)
  - Only contain the main content area (remove header/navigation/css that's now in base)

### 4. Create Single Layout for Collections
- Create `_layouts/single.html` to:
  - Use base.html as layout (front matter: `layout: base`)
  - Contain the content area for collection items
  - Inherit navigation from base layout

### 5. Verify and Test
- Ensure all pages (index, blog, projects, experience, education, etc.) show navigation
- Verify News and Resources tabs are removed
- Check that styling is consistent across all pages

## Files to Modify/Create
1. `_data/navigation.yml` - remove News and Resources
2. `_layouts/base.html` - new file with header/navigation
3. `_layouts/default.html` - update to use base layout
4. `_layouts/single.html` - new file for collection items
